## Discussion

All this questions should be answered in the kickoff meeting:

- What kind of system is required to build
- Architecture overview of the system
- Communication with the team by Project Manager
- Devops, who provides repository and infrastructure?
- QA, who make sure code is tested?
- Deadlines
- Connectivity with other teams or 3pp

After this initial meetings, more specific meetings should take place with
different teams:

- Architecture meeting with tech leads
- Meeting with Product Owners to discuss details in depth
- Ceremonies in place, usually held by Project Manager
